# Pixtron Systems

Corporate website for Pixtron Systems — high-speed machine vision inspection.

## Run Locally

**Prerequisites:** Node.js 18+

1. Install dependencies:
   `npm install`
2. Copy `.env.example` to `.env` and fill in your keys
3. Run the app:
   `npm run dev`
4. Run with API server (for contact form):
   `npm run dev:all`

## Build

```bash
npm run build
```

Output goes to `dist/`.
